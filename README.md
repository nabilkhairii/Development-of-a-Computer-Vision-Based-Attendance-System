# Development-of-a-Computer-Vision-Based-Attendance-System
This project aims to develop a comprehensive student attendance system by integrating front-end and back-end development with digital image processing to enhance data accuracy. The development process involved designing system workflows via flowcharts , building a graphical user interface (GUI) using Tkinter and OpenCV for real-time camera access , and implementing a centralized database management system using XAMPP (Apache & MySQL).
